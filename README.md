Winter Arc: The Gu Master's 90 Days ⚔️

A 90-day habit and goal-tracking web app inspired by the cultivation system of Reverend Insanity.

Instead of treating self-improvement as a simple checklist, I designed it as a progression system where every productive day contributes to your cultivation journey.

⚡ Key Features

- 90 levels across 9 ranks — progress from Rank 1 Gu Master to Rank 9 Gu Immortal.
- Primeval Essence system — complete daily tasks to gain essence and level up.
- Customizable daily tasks — training, deep work, studying, clean eating, cold showers, journaling, sleep, and more.
- Tribulations — challenging real-life objectives that must be completed to break through certain ranks.
- Aptitude Grade & Vital Gu — additional progression mechanics inspired by the novel.
- Spring Autumn Cicada — a rewind mechanic designed around recovering from failed days.
- Primeval Stones & Dao Marks — additional progression and reward mechanics.
- 90-day progression dashboard — track your cultivation journey and consistency.

🛠️ Technical Approach

The project is built as a single self-contained HTML application, requiring:

- No backend
- No database
- No build process
- Local data storage
- Fully customizable task and progression system

The project focuses on combining gamification, habit formation, and fictional world-building into one interactive experience.

This is an unofficial fan project inspired by Reverend Insanity by Gu Zhen Ren. It is not affiliated with the author or any publisher, and the maxims used in the app are original.

The goal was simple: turn discipline into cultivation.
